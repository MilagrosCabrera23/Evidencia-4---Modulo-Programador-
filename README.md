# Diseño y Desarrollo de Objetos

## Descripción del Proyecto
Este proyecto individual tiene como objetivo diseñar y desarrollar una clase en Python que represente un objeto con funcionalidad lógica, aplicando los principios de la programación orientada a objetos (POO) y el desarrollo guiado por pruebas (TDD). Además, incluye el diseño de una base de datos relacional que represente el objeto.

---

## Objetivos
1. Diseñar una clase en Python aplicando principios de POO (abstracción, encapsulamiento).
2. Implementar TDD para desarrollar y probar los métodos de la clase.
3. Crear una base de datos con una tabla que represente el objeto, insertar datos de ejemplo y realizar consultas.
4. Documentar el proceso y reflexionar en un video explicativo.

---

## Instrucciones
### 1. Selección y Diseño del Objeto
- **Selección:** Elegir un objeto propuesto en la lista asignada.
- **Definición:** Implementar al menos 3 comportamientos clave del objeto que involucren lógica de programación.
  - Ejemplo para un vehículo:
    - **Acelerar:** Incrementa la velocidad de 10 en 10 km/h hasta un máximo.
    - **Frenar:** Disminuye la velocidad de 15 en 15 km/h hasta detenerse.
    - **Consumo de combustible:** Calcula el consumo basado en la velocidad y distancia.
- **Método estándar:** Incluir al menos un método especial (`__str__`, `__len__`, `__add__`, etc.).

### 2. Desarrollo Guiado por Pruebas (TDD)
- Escribir primero las pruebas unitarias.
- Implementar la clase para que pase todas las pruebas.
- Refactorizar el código según sea necesario.

### 3. Base de Datos
- Diseñar una base de datos relacional:
  - Crear la tabla correspondiente con **PK**, **FK**, y demás restricciones necesarias.
  - Escribir 10 sentencias `INSERT` con datos de ejemplo.
  - Escribir 5 consultas `SELECT` relevantes.
  
### 4. Documentación y Reflexión en Video
- Grabar un video de **máximo 60 segundos** que incluya:
  - Explicación del código y cómo aplica principios de abstracción y encapsulamiento.
  - Experiencia trabajando con TDD.
  - Demostración del programa en funcionamiento.
